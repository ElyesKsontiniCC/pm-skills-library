# Competitors — ClearCompany (ATS / Talent Management)

Tracked competitor set for `/competitive-pulse` and `/landscape-mapper`. Update this file as win/loss themes emerge — skills read it as the seed list instead of guessing.

## Direct ATS Competitors
- **Greenhouse** — ATS, strong in structured hiring/interview kits
- **Workday** — full HCM suite with ATS (Workday Recruiting); enterprise-heavy
- **Lever** — ATS, CRM-style sourcing/pipeline focus
- **iCIMS** — ATS, enterprise/high-volume hiring
- **Ashby** — newer ATS, analytics/reporting-forward, tech/scaleup focus
- **SmartRecruiters** — ATS, mid-market/enterprise
- **Jobvite** — ATS
- **JazzHR** — ATS, SMB-focused

## Adjacent HCM / Payroll Suites (compete via bundled ATS module)
- **ADP** — payroll/HCM with ATS capability; frequently the incumbent ClearCo displaces or loses to on bundling
- **UKG** — payroll/HCM with ATS capability; same dynamic as ADP
- **Oracle** (HCM Cloud) — enterprise HCM suite

- **Absorb**
